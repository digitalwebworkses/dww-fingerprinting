# Guía de usuario

## 1. Activar Fingerprinting en un producto

1. Editar el producto en WooCommerce.
2. Activar **DWW Fingerprinting**.
3. Añadir uno o varios activos maestros.
4. Seleccionar el formato correspondiente.
5. Guardar el producto.

## 2. Qué ocurre después de una compra

Cuando el pedido se procesa correctamente:

- se genera una copia personalizada;
- se crea un fingerprint único;
- se registra la trazabilidad;
- se genera un token de descarga;
- el cliente puede descargar el archivo desde **Mi cuenta**.

## 3. Consultar fingerprints

Ir a:

**DWW Fingerprinting → Fingerprints**

Desde ahí se puede:

- buscar por fingerprint, cliente, pedido o producto;
- consultar el estado del token;
- ver el historial de descargas;
- abrir el detalle de cada registro.

## 4. Verificar un documento

Ir a:

**DWW Fingerprinting → Verificar documento**

Seleccionar el archivo y pulsar **Verificar documento**.

El sistema comprobará:

- autenticidad;
- integridad;
- correspondencia con la base de datos;
- estado del payload;
- nivel de confianza.

## 5. Diagnóstico del sistema

Ir a:

**DWW Fingerprinting → Doctor**

Desde esta pantalla se puede comprobar:

- entorno PHP;
- WordPress;
- WooCommerce;
- base de datos;
- almacenamiento;
- handlers;
- formatos soportados;
- migraciones.

## 6. API REST

Ir a:

**DWW Fingerprinting → API REST**

Desde ahí se puede:

- generar o regenerar la API Key;
- consultar los endpoints disponibles;
- habilitar integraciones externas.

## 7. Formatos soportados

- PDF
- EPUB
- DOCX
- XLSX
- PPTX
- ODT
- ODS
- ODP
